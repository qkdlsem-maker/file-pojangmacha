# 파일 포장마차 0.4.11 무료 베타

**사진 스무 장, PDF 한 봉지 나왔습니다.**

파일 포장마차는 화면 구석의 작은 포장마차에 실제 파일을 끌어 넣고, 원하는 파일로 포장해 꺼내는 Windows 앱입니다. 처음에는 웃기고, 다음부터는 파일 정리가 편해지는 작은 도구를 목표로 만들었습니다.

사진 여러 장을 넣으면 조리대에 썸네일이 펼쳐집니다. 표지를 고르고 순서를 바꾼 다음 용지·방향·여백을 확인해 PDF를 만드세요. 완성된 갈색 PDF 봉지를 탐색기의 빈 폴더로 끌면 실제 PDF 파일을 가져갈 수 있습니다.

## 할 수 있는 일

- 사진 여러 장을 PDF 하나로 만들기
- PDF 여러 개 합치기, 원하는 쪽 추출·나누기
- 이미지 여러 장의 크기를 비율 그대로 일괄 변경하기
- 자주 쓰는 설정을 ‘늘 먹던 거’로 저장하고 다시 사용하기
- 작게 접어 두기, 파일 선택과 탐색기 드래그, 최근 결과 다시 열기

파일은 컴퓨터 안에서 처리합니다. 앱 사용에 가입·결제가 필요 없고, 원본은 보존하며 같은 이름의 결과를 조용히 덮어쓰지 않습니다. 컴퓨터 전체 활동을 감시하지 않습니다.

## 설치하고 시작하기

1. [Windows x64 설치 파일 받기](https://github.com/qkdlsem-maker/file-pojangmacha/releases/download/v0.4.11-beta.1/FilePojangmacha-0.4.11-Setup-x64.exe)
2. 설치 후 실행하고 사진이나 PDF를 작은 포장마차로 끌어 넣습니다.
3. 순서·설정·저장 위치를 확인한 다음 포장합니다.
4. 완성 파일을 열거나 봉지를 탐색기로 끌어 꺼냅니다.

**한국어 UI의 서명 없는 무료 베타입니다.** Windows 게시자 확인 경고가 나타날 수 있습니다. Windows 11 x64 개발 PC에서 확인했으며 다른 실제 PC, Windows 10, ARM64는 아직 검증하지 않았습니다. 업데이트는 새 설치 파일을 직접 받아 진행합니다.
