# File Pojangmacha 0.4.11 — Free Beta

**Twenty photos. One bag of PDF. Order up.**

File Pojangmacha is a tiny Korean street-food stall for your Windows desktop. Drop in real files, arrange them on the counter, and take away a real PDF or resized images. It aims to be funny at first glance and useful the next time you need to prepare files.

Drop in a batch of photos to see their thumbnails. Choose a cover, change the order, and check paper size, orientation and margins before making a PDF. Drag the finished brown PDF bag into an empty area of an Explorer folder to take the actual file with you.

## What's on the menu?

- Combine multiple photos into one PDF
- Merge PDFs, extract selected pages, or split pages into separate files
- Batch-resize images while preserving their aspect ratios
- Save frequently used settings as “your usual order”
- Fold the stall down, use file picking or Explorer drag-and-drop, and reopen recent results

Files are processed locally. Using the app requires no account or payment. Originals are preserved, and existing output files are not silently overwritten. The app does not monitor computer-wide activity.

## Install and get started

1. [Download the Windows x64 installer](https://github.com/qkdlsem-maker/file-pojangmacha/releases/download/v0.4.11-beta.1/FilePojangmacha-0.4.11-Setup-x64.exe).
2. Install and launch, then drop photos or PDFs onto the small stall.
3. Check order, settings and destination, then cook.
4. Open the result or drag the bag into Explorer.

**This is an unsigned free beta with a Korean interface.** This English introduction does not imply an English app UI. Windows may display a publisher warning. Testing was performed on one Windows 11 x64 development PC; another physical PC, Windows 10 and ARM64 remain unverified. Updates are manual: download and run the newer installer.
