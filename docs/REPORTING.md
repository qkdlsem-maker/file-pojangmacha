# 파일 포장마차 문제 제보 / Reporting a problem

- [한국어 양식 열기](https://github.com/qkdlsem-maker/file-pojangmacha/issues/new?template=bug-ko.yml)
- [Open the English form](https://github.com/qkdlsem-maker/file-pojangmacha/issues/new?template=bug-en.yml)
- [문제 제보·기능 제안 선택 / Choose report or feedback](https://github.com/qkdlsem-maker/file-pojangmacha/issues/new/choose)

제보에는 GitHub 로그인이 필요합니다. 앱 사용에는 계정이 필요 없습니다. 제보는 공개되므로 개인정보, 비밀번호, 전체 사용자 경로, 원본 업무 문서를 첨부하지 마세요. 첨부는 선택입니다.

Submitting a report requires a GitHub login; using the app does not. Reports are public. Do not attach personal data, credentials, full user paths or confidential documents. Attachments are optional.

한국어·영어 양식은 앱 버전, Windows 환경, 작업 종류, 재현 절차, 기대한 결과와 실제 결과, 선택적 첨부를 받습니다. 설치·제거, 사진 PDF, PDF 합치기·분리, 이미지 크기 변경, 탐색기 드래그, 저장 주문과 최근 결과를 구분할 수 있습니다.

Both forms collect the app version, Windows environment, affected task, reproduction steps, expected and actual result, and optional attachments. Task choices cover installation/removal, photo PDFs, PDF merge/split, image resizing, Explorer drag-and-drop, saved orders and recent results.

`ISSUE-FORMS-0.4.11.zip` is a downloadable backup of the live GitHub issue forms, not a separate submission service. Use the links above to submit a report. The original form definitions are in `.github/ISSUE_TEMPLATE` on the repository's default branch.
