# 파일 포장마차

**사진 스무 장, PDF 한 봉지 나왔습니다.**

사진과 PDF를 작은 포장마차에 끌어 넣고, 순서를 확인한 뒤 실제 파일로 꺼내는 Windows 앱입니다. 파일은 내 컴퓨터에서 처리합니다. 회원가입과 결제 없이 사용할 수 있습니다.

[Windows x64 무료 베타 0.4.11 다운로드](https://github.com/qkdlsem-maker/file-pojangmacha/releases/tag/v0.4.11-beta.1) · [English](README.en.md) · [문제 제보](https://github.com/qkdlsem-maker/file-pojangmacha/issues/new/choose)

![붉은 천막과 녹색 조리대, 사진 순서를 확인하는 실제 앱 화면](docs/workspace.png)

## 한 봉지로 할 수 있는 일

| 주문 | 실제 기능 |
| --- | --- |
| 사진 한 봉지 | 여러 사진 → PDF. 썸네일, 표지, 순서 변경·제외, 용지·방향·여백 미리보기 |
| PDF 모둠 포장 | PDF 합치기. 필요한 쪽을 골라 원하는 순서로 묶기 |
| 필요한 만큼 썰기 | PDF 페이지 추출, 선택한 쪽을 한 파일 또는 각각 저장 |
| 같은 규격으로 맞추기 | 이미지 일괄 크기 변경. 긴 변 또는 최대 가로·세로, 비율 유지, PNG/JPG |
| 늘 먹던 거 | 이름·설정·선택한 저장 폴더를 주문으로 저장, 수정·삭제 |

작게 접어 두기, 창 이동, 최소화·종료, 빠른 모드, 최근 결과, 이미지 붙여넣기와 탐색기 ‘보내기’를 지원합니다. 진행률은 실제 처리 상태를 반영합니다.

## 설치하고 써 보기

1. 릴리스의 **FilePojangmacha-0.4.11-Setup-x64.exe**를 받습니다. GitHub의 자동 생성 ‘Source code’ ZIP은 설치 파일이 아닙니다.
2. 설치 후 실행하고 작은 포장마차에 사진을 끌어 넣습니다. ‘파일 고르기’도 가능합니다.
3. 조리대에서 순서·표지·선택한 쪽을 확인하고 오른쪽 주문표에서 설정과 저장 폴더를 정합니다.
4. 포장 후 파일을 열거나, 갈색 봉지의 큰 **PDF** 글자를 잡고 탐색기의 빈 파일 영역으로 끌어 꺼냅니다. ‘탐색기에서 보기’는 저장한 위치를 엽니다.
5. 다음부터는 빠른 주문이나 저장한 ‘늘 먹던 거’를 사용합니다. 기본 저장 위치는 다운로드 폴더 안의 ‘파일 포장마차’입니다.

**무료 베타 · Windows x64 · 한국어 앱 UI · 코드 서명 없음.** Windows 게시자 확인 경고가 나타날 수 있습니다. 서명된 정식 안정판으로 소개하지 않습니다. [검증 범위와 한계](docs/VALIDATION-0.4.11.md)를 먼저 확인하세요. SHA256SUMS.txt로 다운로드의 파일 일치 여부를 확인할 수 있습니다. 업데이트는 새 설치 파일을 직접 받아 실행하는 방식입니다. Windows 설정의 설치된 앱에서 제거할 수 있습니다.

## 실제 시연

[24초 영상 다운로드/재생](https://github.com/qkdlsem-maker/file-pojangmacha/releases/download/v0.4.11-beta.1/FilePojangmacha-0.3.1-native-drag-demo.mp4)

**영상은 0.3.1 설치 앱을 실제로 촬영했습니다.** 탐색기 사진 입력 → 표지·순서 변경 → PDF 생성 → 봉지를 새 폴더로 끌기 → PDF 뷰어 열기를 담았습니다. 창 사이 드래그는 사람이 직접 수행했고, 중간 버튼은 Windows 조작 도구를 사용했습니다. 대기와 개인 화면을 잘랐습니다. 0.4.11은 같은 디자인·기능의 새 버전 빌드이며, 이 영상을 새 버전의 재촬영 증거로 표시하지 않습니다.

## 원본과 개인정보

파일을 서버로 올리지 않고 로컬에서 처리합니다. 계정, 결제, 분석 추적, 자동 업데이트가 없습니다. 원본은 보존하고 결과는 따로 저장하며 같은 이름에는 `(1)`, `(2)`를 붙입니다. 오류·취소 시 작업의 미완성 결과를 정리합니다. 전원이 갑자기 꺼지면 `.partial` 임시 파일이 남을 수 있습니다.

주문·마지막 저장 폴더와 최근 20개 결과의 경로·크기는 `%APPDATA%\file-pojangmacha`에 저장합니다. 입력 목록은 종료 시 사라집니다. 클립보드는 붙여넣기를 요청할 때만 읽습니다. 붙여넣기 임시 이미지는 정상 종료 시 삭제합니다. 제거 후에도 주문과 최근 기록은 남습니다. ‘최근 포장 → 기록 비우기’는 실제 파일을 지우지 않습니다.

## 지원 범위

- JPG, PNG, WebP, 단일 페이지 TIFF, 암호 없는 PDF. HEIC, GIF, SVG, 영상, OCR 미지원.
- 한 번에 120개 파일, 파일당 150MB, 총 300MB, 한 주문 400쪽 이하.
- 사진 PDF는 긴 변 최대 4,000px, JPEG 품질 94입니다. 투명 배경은 흰색으로 처리합니다. 무손실 보관용이 아닙니다.
- PDF 책갈피·전자서명·문서 첨부파일은 보존하지 않습니다. 복잡한 양식은 별도 확인이 필요합니다.
- 로컬 NTFS 저장을 검증했습니다. FAT/exFAT·일부 네트워크 폴더는 안전한 저장 방식과 호환되지 않을 수 있습니다.
- Windows 11 x64 개발 PC에서 검증했습니다. 다른 실제 PC, Windows 10, ARM64, 다양한 화면 배율은 미검증입니다.
